# AGClass — сайт Галины Сергеевны Аслановой

Одностраничный статический сайт: курсы английского и подготовка к ОГЭ по информатике.
Без сборщика и зависимостей: `site/index.html` + `site/styles.css` + `site/fonts.css` + `site/main.js`.
После правок поведения прогонять `tests/behave.js` (как — в HANDOFF.md, «Задачи»).

Перед любой работой прочитай `HANDOFF.md` — там дизайн-замысел, поведение и список задач.

Жёсткие правила:
- Сайт должен отлично смотреться на телефоне (390 px). Горизонтальной прокрутки страницы быть не должно нигде.
- Не используй `overflow: hidden` на предках липких элементов — это ломает `position: sticky`. Используй `overflow: clip`.
- Тексты на русском, тон простой и тёплый. Не выдумывай цены, сроки и цифры, которых нет в контенте.
- Британские мотивы — без банальщины: никаких флага, красных автобусов и знака метро с кругом. Биг-Бен — только в силуэте Лондона в шапке (заказчик попросил узнаваемый силуэт).
- Уважай `prefers-reduced-motion`.
- Инлайн-стили не добавлять: цвета и шрифты — переменные из `:root`, оформление — классы в `styles.css`.
- У `<img>` с атрибутами width/height обязателен `height: auto`, иначе фото растягивается до высоты из атрибута.
